## 3. Payline Definitions

**Mystic has no paylines.** Wins are awarded by **cluster**, not by line. [engine-shared]

A cluster is a group of **5 or more identical symbols connected orthogonally** (horizontally
or vertically adjacent). Key rules:

- **Diagonal connections do not count as adjacent.** (`09_Mahjong 7x7.md`, Features §1 "Cluster model")
- **Clusters are any connected shape, not straight lines.** The cluster-model diagram
  (`09_Mahjong 7x7.md` Features §1, embedded `[image12]`) shows L-shapes, T-shapes, plus-shapes
  and crosses in its "Yes" column. The prose — "Match 5 or more identical symbols horizontally
  or vertically" — reads as if a straight line of 5 is required; **the diagram overrides this
  reading**. Treat a cluster as an orthogonally-connected component of size ≥ 5.
- **The Scatter is excluded from clusters:** "A cluster is a group of 5 or more identical
  symbols horizontally or vertically adjacent. **Except for the Scatter symbol.**"
- **Cluster size is capped at 15.** `paytable.json` `Payouts.SymbolOccurenceLimit: 15`; no
  payout is defined above `OccurenceCount: 15`.

Cluster payouts per size are in [paytable.md](paytable.md).

## 4. Mechanics

### Confirmed Mechanics

**Free Spin** — vs `shared-mechanisms/free-spin.md`: **Deviates**

- How it works here: Triggered when **at least 3 reels show a Scatter, with at least 1 Scatter
  on each of those reels** (`09_Mahjong 7x7.md`, Features §3 "Freespin") [engine-shared].
  Award is by *reel count*, per `paytable.json` `FreeSpins`: 3→8, 4→10, 5→12, 6→14, 7→16 spins.
  Each FS round starts at the **Free Game multiplier ladder level 1 = x2** and progresses
  x2→x4→x6→x10→x16→**x20 (cap)** (`paytable.json` `FreeGame.MultiplierLevels`).
  Retriggerable **unlimited** times. Bet button, bet-amount setting, and Auto Play are locked
  for the duration.

- Comparison — four concrete deviations from the shared pattern:
  1. **Trigger is reel-based, not symbol-count-based.** The shared pattern assumes "landing a
     minimum number of scatter/bonus symbols". Here, "Multiple Scatters on the same reel count
     as one" (`09_Mahjong 7x7.md`, Symbol Mapping row 1) — so 5 scatters spread across only
     2 reels does **not** trigger. Tests must control scatter *reel spread*, not scatter count.
  2. **Retrigger is unbounded.** "FS can be retriggered **unlimited times** if the Scatter
     condition is met again." (Features §3). Shared Pattern E assumes retrigger exists but does
     not address an unlimited cap.
  3. **Free spins carry a separate multiplier ladder.** "Each FS bet round starts with
     multiplier = x8. (this is level 1 Freespin paytable)" (Features §3) — structurally true,
     but the **value x8 is Mahjong's**; Mystic's level 1 is **x2** per `paytable.json`. The
     shared pattern has no multiplier concept at all.
  4. **Shared Patterns F and G are inapplicable.** There is no Buy Bonus entry and no
     promotional grant path documented for this game.

**Auto Spin** — vs `shared-mechanisms/auto-spin.md`: **Unknown — comparison not possible**

- How it works here: QA confirmed (2026-07-17) that Auto Spin **is a real feature** of this
  game. The only documentary evidence is indirect: "In FS mode, lock these buttons: Bet button,
  Set button amount, **Auto play button**" (`09_Mahjong 7x7.md`, Features §3), plus an autoplay

- Comparison: **cannot be performed.** The raw docs do not describe Auto Spin's spin-count

  Mystic's own spec or confirmed against the live build** — do not assume the canonical
  `auto-spin.md` pattern holds here.

### Custom Mechanics (Game-Specific)

**Tumble / Cascade** [engine-shared] — `09_Mahjong 7x7.md`, Features §2 "Base game".
Symbols drop into the grid from above. On each reel stop:

1. If at least one winning cluster exists → `StepWin = (total payout of all clusters this step) × current Multiplier × Total Bet`
2. StepWin is added to the round's Total Win
3. **Remove winning icons** — the symbols that contributed to the win are removed
4. **Check multiplier** — if the max level has been reached, keep it; otherwise advance one level
5. **Tumble** — new symbols drop from above to fill the empty spots
6. If new clusters form → repeat from step 1. If no more clusters → the spin round ends.

Final payout = the accumulated Total Win for the round. If no wins occur, the round pays 0.

**Progressive Multiplier** [engine-shared, values from `paytable.json`] — a multiplier that
advances one level per *winning cascade step*, not per spin.

- **Reset:** "At the start of each new bet round: the multiplier is reset to x1 (level 1)"
  (Features §2). For Mystic, base-game level 1 = **x1**; free-game level 1 = **x2**.
- **Progression (Mystic):** base game **1 → 2 → 3 → 5 → 8 → 10**; free game **2 → 4 → 6 → 10 → 16 → 20**.
  Both ladders have **6 levels** (`paytable.json` `BaseGame.MultiplierLevels` /
  `FreeGame.MultiplierLevels`). The x1024 cap and 11-level ladder in the Mahjong doc are
  **Mahjong's and do not apply**.
- **Cap:** once the top level is reached the multiplier stays there for the rest of the round.

**Multi Bar** [engine-shared] — the multiplier display arc above the reels
(`09_Mahjong 7x7.md`, Features §4, embedded `[image13]`). It renders the multiplier ladder with
the **current level highlighted**, advancing as the tumble chain progresses. For Mystic it
should show the 6-level ladder, not Mahjong's 11-level one.

**Win Tier Thresholds** — QA-confirmed as applying to Mystic (2026-07-17).
`09_Mahjong 7x7.md`, Features §6 "Win Tier Multiplier". Thresholds are relative to Bet:

| Tier | Condition |
|------|-----------|
| Small Win | `0x < win ≤ 2.5x` |
| Mid Win | `2.5x < win ≤ 6x` |
| Big Win | `6x < win < 15x` |
| Mega Win | `15x ≤ win < 40x` |
| Ultra Win | `win ≥ 40x` |

Note the boundary at 6x: Mid Win is inclusive (`≤ 6x`) and Big Win is exclusive (`> 6x`), so a
win of exactly 6x is a **Mid Win**. Exactly 15x is a **Mega Win**; exactly 40x is an **Ultra
Win**. These are as-written in the source — worth an explicit boundary test.

1. **Symbol artwork is undocumented for Mystic.** The only symbol art available is Mahjong's.
   Reference images must be added to `docs/assets/symbols/` before AI visual assertions can
   run. See `docs/assets/assets.yml`.

3. **Stale text in the source doc:** the Symbol Mapping table states "At least 3 Scatters on the
   reels are required to trigger **10 Free Spins**". QA confirmed 2026-07-17 this is **stale** —
   the correct award for 3 scatter-reels is **8** free spins (`paytable.json` `FreeSpins`,
   corroborated by the doc's own Features §1 award table).
4. **Reel-distribution weights differ between the two sources.** Mystic's are 12/77/11 (base) and
   33/34/33 (free) per `paytable.json`. The doc's 40/30/30 is Mahjong's. See [paytable.md](paytable.md).

   mockup `[image13]`, but no doc describes its behaviour. Out of scope until specified.
6. **RTP is not documented** in either source file.
7. **Bet levels / denominations are not documented** in either source file.
8. **Loading-screen and game-screen layout** are image-only in the source doc, and one section is
   marked "This content is only supported in a Lark Docs" (Game Logic §2) — the content is not

9. **`ReelDistributionThreshold: 1`** appears in both `BaseGame` and `FreeGame` in
